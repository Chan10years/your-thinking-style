# YourThinkingStyle 视觉入口设计

## 目标

在不引入账号系统、不改变分析 API 与 MVP 数据结构的前提下，将现有单页工作台扩展为：

1. `/`：品牌视觉入口。
2. `/explore`：核心卖点二级页，交互展示“思路还原 / 错误解释 / 修正方向”。
3. `/analyze`：保留现有分析表单与请求逻辑的工作台。

## 视觉方向

以 Offsite 首页为主要参考，采用暖白画布、大型高对比衬线标题、极小等宽标签、宽松留白和少量不对称信息块。

- 背景：暖白 `#f8f6f3`
- 主文字：近黑棕 `#0e0807`
- 次要文字：灰棕 `#69635f`
- 分隔线：半透明黑棕
- 错误强调：保留产品语义红
- 核心算法强调：保留产品语义蓝

字体角色：

- 品牌字标：花体 `Think`，复杂、连写、只用于 Logo。
- 主标题：高对比衬线字体，承担页面视觉中心。
- 正文：简洁无衬线字体。
- 标签与说明：等宽字体。

## 首页

- 顶部居中悬浮白色导航胶囊。
- 左侧展示花体 `Think` 字标，下方或辅助位置显示完整产品名 `YourThinkingStyle`。
- 右侧菜单按钮可展开导航抽屉。
- 首屏中央是三行大型中文主标题：“看懂你的思路 / 再看代码 / 哪里偏离”。
- 标题上方使用小号等宽眉题。
- 左下角用短文解释产品不是标准答案机器。
- 右下角使用一张低调的学习场景预览图，点击进入 `/explore`。
- 动效只包含首屏渐入、标题轻微上移和按钮/图片悬停反馈；支持 reduced motion。

## 核心标签页

- 沿用首页视觉系统，但信息密度略高。
- 三个标签固定使用“思路还原 / 错误解释 / 修正方向”。
- 每个标签展示同一个示例在不同诊断阶段的内容，切换时只更新主内容，不增加多余卡片。
- 页面底部提供“开始探索”，进入 `/analyze`。

## 工作台

- 将现有表单迁移至 `/analyze`，不改变提交、验证、API Key 内存保存与 API 请求行为。
- 只调整外层品牌导航、颜色、排版、边框与按钮，使其与入口页统一。
- C++ 固定、输入限制、补充信息与所有错误提示保持原样。

## 响应式与可访问性

- 桌面优先，同时保证移动端不溢出。
- 菜单、标签与主要按钮可键盘操作，并有清晰焦点状态。
- 文本与背景保持足够对比。
- 尊重 `prefers-reduced-motion`。

## 明确不做

- 不实现登录、注册或持久化账号。
- 不修改 DeepSeek Schema、API 路由或输入限制。
- 不加入在线运行、编译或判题。
- 不增加工作台之外的新业务功能。
